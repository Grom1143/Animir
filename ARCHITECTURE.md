Зависимости модулей — без циклов, низ (config, shiki_net, sources/net) ни от кого не зависит:

```
Animir.pyw ─► app_window, server, windows, tray, shiki_net, config
app_window ─► windows, config
server     ─► shiki_data, shiki_auth, media, state, windows, sysinfo, shiki_net, sources
sources    ─► net ◄─ shiki ◄─ aniliberty, kodik ◄─ anixart;  search ─► kodik;  counts ─► search
```

## Как окна узнают друг о друге

`windows.py` держит крючки, а `app_window.py` их заполняет, только если своё окно запустилось:

| Крючок | Кто зовёт | Что делает |
|---|---|---|
| `ON_SHOW` | второй запуск (`/api/show`), трей | вывести главное окно |
| `ON_OPEN` | `/api/open-window` | открыть окно плеера или переключить уже открытое на новую серию |
| `PLAYER` | `/api/player`, `/api/player/close` | что идёт в окне плеера; закрыть его |

Пустые крючки — значит окна в Edge, и всё работает по-старому. Поэтому сервер и тесты не знают про pywebview.

Плеер одновременно один: перед новой серией страница спрашивает `/api/player` и, если что-то идёт,
показывает «Сейчас идёт: … Переключить на серию 2?». Где открывать плеер — настройка
«Воспроизведение → Окно плеера» (`settings.playerWindow`: `main` или `separate`).

## Шаги перехода к самостоятельному приложению

1. ✅ **Своё главное окно** (`app_window.py`) вместо Edge `--app`: значок, тёмный заголовок под тему,
   крестик — в трей, второй запуск выводит окно, видео во весь экран разворачивает окно, работают скачивания.
2. ✅ **Своё окно плеера** — одно на всё приложение, не поверх всех (📌 — вручную), серии переключаются в нём же.
3. ⏸ **Мост вместо HTTP** — решено не делать. Видео, постеры и субтитры всё равно идут через локальный
   сервер (hls.js, `/img`), так что порт остаётся. Перевод ~60 маршрутов на `pywebview.api` не уберёт его,
   а только удвоит способы общения окна с Python.
4. ⏸ **Одна копия данных на все окна** — решено не делать. Окна — отдельные страницы со своим JS, общая копия
   в памяти им недоступна; слияние в `state.py` покрыто тестами и работает.
5. ✅ **`sources.py` → пакет `sources/`** (8 модулей по 80–270 строк). Проверено на живых данных:
   старая и новая версия дают одинаковые озвучки и ссылки. ⏸ `server.py` (650 строк) пока целиком —
   это один обработчик с цепочкой маршрутов; резать его стоит вместе с переходом на таблицу маршрутов.
6. ✅ **Сборка exe** (PyInstaller + pywebview): `Animir.exe` ~23 МБ, проверен запуск, окна, плеер.
