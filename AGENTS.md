# Анимир — правила для ИИ-агентов

Этот файл читают оба агента: Claude Code (через `CLAUDE.md`) и DeepSeek Harness (сам). Здесь — только особенности
проекта. Общие правила совместной работы (ветки, доска задач, ревью, секреты) — в `~/.agents/AGENTS.md`, они действуют
и здесь. Комментарии, документацию и сообщения коммитов пишем по-русски.

## Что это
Десктопный аниме-клиент для Windows: Python-сервер на `127.0.0.1:8790` + интерфейс HTML/CSS/JS в своём окне на WebView2 (запасной вариант — Edge `--app`),
значок в трее, каталог Shikimori, онлайн-озвучки.

| Файл | Что внутри |
|---|---|
| `Animir.pyw` | запуск: один экземпляр, трей, окно, прогрев соединений |
| `app_window.py` | свои окна на WebView2 (pywebview): главное (крестик — в трей) и одно окно плеера; нет pywebview — окна открывает Edge `--app` |
| `server.py` | HTTP-сервер: ответы, защита Host/Origin, эксклюзивный порт, выбор обработчика по таблице `server_routes.py` |
| `server_app.py`, `server_shiki.py`, `server_online.py`, `server_files.py` | обработчики маршрутов по темам (`@get` / `@post`) |
| `shiki_net.py` | весь трафик к Shikimori: лимит запросов, пул keep-alive соединений, загрузка картинок; пулом пользуются и онлайн-озвучки (`sources/`) |
| `shiki_data.py`, `shiki_auth.py`, `shiki_colls.py`, `reviews.py` | данные Shikimori, кэш, вход, коллекции, отзывы |
| `sources/` | онлайн-озвучки: `net` (паузы, повторы, кэш), `aniliberty` / `kodik` / `anixart`, `shiki` (названия и части франшизы), `search`, `counts`; снаружи — только то, что в `__init__.__all__` |
| `state.py` | закладки и настройки, трёхстороннее слияние окон |
| `web/` | интерфейс: `index.html`, `js/*.js`, `css/` |

## Проверка
- Юнит-тесты, без интернета: `python -m unittest discover -s tests`. Должны проходить всегда.
- Интерфейс в браузере, нужны интернет и `pip install playwright`: `python tests/ui_smoke.py`.
- Сервер для ручной проверки — только с временной папкой данных, чтобы не тронуть настоящие закладки:
  PowerShell `$env:APPDATA = "$env:TEMP\animir-test"; python server.py 8799`.
- Настоящие данные пользователя (`%APPDATA%\Animir`) не читать и не менять.
- Настоящее окно WebView2 можно проверить Playwright: запуск с `ANIMIR_DEVTOOLS_PORT=9333` (и временной `APPDATA`),
  потом `chromium.connect_over_cdp("http://127.0.0.1:9333")`; выключать — `POST /api/quit`.

## Правила кода
- Стиль — как в окружающем коде: короткие функции, комментарии по-русски объясняют «почему», а не «что».
- Новое поведение и исправленный баг — сначала тест, который падает, потом код.
- Секреты (токены, ключи, `client_secret`) в репозиторий не попадают: они живут в `%APPDATA%\Animir`.
- Зависимости не добавлять без нужды: сервер работает на стандартной библиотеке Python (+ Pillow по желанию).
  Окну нужен `pywebview` (`pip install pywebview`); без него Анимир откроется в Edge, как раньше.

## Работа вдвоём в этом проекте
Общие правила — `~/.agents/AGENTS.md`. Особенности Анимир:
- Доска задач проекта — `C:\Users\OVER_\projects\Анимир\TASKS.md` (только в основной папке, в git не хранится).
- Основная папка `C:\Users\OVER_\projects\Анимир` (ветка `main`) — версия, которую запускает ярлык на рабочем столе.
  Рабочие папки агентов — рядом: `..\Анимир-dsh-<задача>`, `..\Анимир-claude-<задача>`.
- Перед слиянием в `main` обязательно зелёные `python -m unittest discover -s tests`; если менялись сеть или
  интерфейс — ещё и `python tests/ui_smoke.py`.
